# 📝 T5 Text Summarizer

An AI-powered text summarization web application built using a fine-tuned **T5 Transformer model** and **FastAPI**.

## 🚀 Features

- Text summarization using a fine-tuned T5 model
- Transformer-based NLP
- FastAPI backend
- Simple web interface using HTML, CSS, and JavaScript
- Supports long text/dialogue summarization
- REST API endpoint for summarization

## 🛠️ Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- T5
- FastAPI
- HTML
- CSS
- JavaScript
- Uvicorn
